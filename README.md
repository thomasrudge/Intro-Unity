# Polícia e Ladrão

Jogo feito no Unity para o Projeto Introdução ao Unity — Jogos Digitais, Insper.

**Autor:** Thomas Rudge

## Como jogar
Você é o ladrão. Pegue as 3 joias antes do tempo acabar e sem ser preso pelo policial.

- **Mover:** WASD / setas / analógico do controle Xbox
- **Botões do menu:** mouse, Enter ou botão A do controle
- **Vidas:** 3 — encostar no policial tira 1 vida
- **Tempo:** 60 segundos
